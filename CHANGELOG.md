
# Changelog

All notable changes to the Core Semantic Pack are recorded here.

The project is experimental. Until the first adopted release, version changes describe the evolution of the working reference model rather than a production compatibility guarantee.

## 0.1.0 — Experimental baseline

- Materializes the architectural specification as a repository-level semantic pack.
- Introduces 51 candidate Core primitives across foundations, epistemics, teleology, agency, and governance.
- Introduces 89 typed Core relations and 23 anti-collapse boundaries.
- Introduces 9 question-contract families.
- Introduces 5 composite patterns for semantic traceability, teleology, institutional memory, execution legitimacy, and semantic status collapse.
- Separates five lifecycle/status families.
- Introduces 18 conformance rules, 5 valid fixtures, and 24 intentionally invalid semantic regression fixtures.
- Adds composition, generic agentic mapping, release, and structural validation records.
