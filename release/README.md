# Releases

A semantic release identifies an immutable set of definitions, relations, boundaries, question obligations, patterns, lifecycle rules, composition rules, mappings, and conformance evidence.

`0.1.0.yaml` is an **experimental release candidate manifest**. It records the intended v0.1 composition but does not become a published immutable release until the governing commit or tag is assigned after merge.

Historical consumers should retain:

- exact semantic pack version;
- resolved component versions;
- governing commit or tag;
- compatibility result;
- checksums or another immutable content identity.

A later release must not silently reinterpret historical objects.
