
# Architecture mappings

Mappings translate Core semantic responsibilities into architecture or implementation vocabularies.

They are deliberately non-authoritative:

```text
Core meaning
    ↓ mapped to
architecture term
    ↓ realized as
implementation artifact
```

A mapping may explain how a runtime carries, validates, persists, or projects meaning. It must not redefine the source concept.

The generic agentic mapping is illustrative. A concrete platform should publish its own reviewed mapping and retain the exact Core release against which it was authored.
