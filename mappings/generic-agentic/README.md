
# Generic agentic mapping

This mapping demonstrates how common agentic-system terms can realize Core responsibilities without entering the Core as primitives.

Terms such as agent, tool, workflow, memory, message, prompt, response schema, and model are architecture or implementation terms. Their meaning depends on the system in which they are used.

A single runtime object may realize several semantic responsibilities, and one semantic responsibility may span several runtime objects. Therefore the mapping is many-to-many and must be reviewed at concrete boundaries.
