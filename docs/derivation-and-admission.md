# Derivation and Core admission

The Core Semantic Pack is derived from a broader runtime-neutral reference model and the structural discipline expressed by the System Momentum Canon and Mindframe. It is not itself the Canon.

A candidate concept should be admitted into the Core only when:

1. an important cross-domain question cannot remain answerable without the distinction;
2. the concept has a stable definition and explicit boundaries;
3. composition of existing primitives is insufficient;
4. the concept survives multiple architecture mappings without changing meaning;
5. incompatible local interpretations would create material semantic risk;
6. lifecycle and compatibility consequences are known;
7. conformance evidence demonstrates both valid use and prohibited collapse.

A concept is not admitted merely because it is familiar agentic terminology, appears in a prompt or schema, or is useful in one workflow.

Current v0.1 concepts remain `experimental` and `candidate-core-primitive` until cross-domain use provides stronger evidence.
