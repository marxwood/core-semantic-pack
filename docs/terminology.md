# Terminology discipline

## Core versus universal

`Core` means minimal reusable kernel. It does not claim a final ontology of everything.

## Process versus execution

```text
Process
  ontology of possible change

Execution Contract
  semantic conditions of legitimate realization

Execution Plan
  optional concrete materialization

Runtime
  actual execution

StateChange
  what changed in reality
```

`Workflow` remains a possible architecture or orchestration term. It is not the fundamental semantic concept responsible for execution legitimacy.

## Memory

`Memory` is not a v0.1 primitive. Institutional Memory is a composite pattern over Persistence, State, Admission, Provenance, Context, SemanticVersion, Validity, Contestation, and StateChange.

## Truth

`Truth` is not represented as a v0.1 Core primitive. The Core governs Claims, Evidence, Validity, Context, Uncertainty, and Contestation. `Evidence != Truth` remains a boundary against implicit universalization.

## CurrentState and PreviousState

These are semantic roles occupied by `State` in relation to a `StateChange`; they are not separate v0.1 primitives.
