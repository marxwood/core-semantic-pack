# Examples

Examples show how Core records can participate in a concrete semantic trace.

They are illustrative and non-authoritative:

- domain terms are represented with `example.*` identifiers;
- no example creates a Domain Pack, Regime Pack, or Execution Contract release;
- the examples do not prove domain truth or production conformance;
- a consumer must resolve its own compatible semantic environment.

The patent portfolio trace follows the architecture specification from Source and Observation through Finding, Goal, Action, Projection, and separately authorized consequence.
