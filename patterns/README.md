# Patterns

Patterns compose Core primitives into reusable semantic structures without promoting every important system concept into a new primitive.

v0.1 includes:

- **Semantic Trace** — reconstructable paths from Source to Finding and from Goal to StateChange;
- **Teleological Loop** — CurrentState, DesiredState, action, and independent Progress evaluation;
- **Institutional Memory** — persistent typed objects with provenance, admission, validity, lifecycle, and version;
- **Execution Contract** — the semantic legitimacy bridge between Process and runtime realization;
- **Semantic Status Collapse** — the failure pattern in which persistence, repetition, visibility, or capability silently creates stronger status.

Patterns are referencable and testable, but they are explicitly marked `not_a_primitive: true`.
